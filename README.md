\# Sistema de Control de Insumos, Nómina y Costos — Gelantásticas



Aplicación web con Node.js, Express y MySQL para administrar proveedores, insumos, nómina/mano de obra y cotización de recetas en líneas \*\*Minorista\*\* y \*\*Mayorista\*\*.
